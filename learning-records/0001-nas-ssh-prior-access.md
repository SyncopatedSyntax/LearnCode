# Prior knowledge: working SSH access to the Synology NAS

The user already has functioning SSH access to their Synology NAS, but is deliberately cautious and does not want to run risky or destructive commands on it. Established at the outset via clarifying questions (see [[MISSION]]).

**Implication:** NAS-touching lessons stay read-only and non-destructive by default; risk must be flagged explicitly before anything that writes, deletes, moves, or reconfigures. Recorded as a standing constraint in [[NOTES]].
