Getting the Most from /teach

The features of this teaching workspace, and how to push each one.

The mental model

/teach isn't software with buttons — it's a convention. This whole directory is the tool. Your learning lives in files, and the agent is the engine that reads and writes them. "Maximizing" it means feeding those files well and asking the agent to exercise the parts you haven't used yet.

The seven moving parts

File / folderWhat it is · how to push it
MISSION.mdThe compass. Every lesson must trace back to it, which stops lessons drifting into abstract trivia. Keep it concrete; tell the agent the moment your goal shifts.
RESOURCES.mdVetted sources + communities. The agent is told never to teach from memory alone. Throw sources at it to vet; ask it to fill "Gaps."
lessons/The main output — short, single-win, pitched to your level. Name what you want, or say "you pick" and it finds your zone of proximal development.
reference/The durable layer — cheat sheets and glossaries you revisit. Ask for one on anything; once a glossary exists it's adhered to.
learning-records/The memory — ADR-style notes of what you actually learned. They drive what's taught next, across sessions.
assets/Reusable components (the shared stylesheet, the dark-mode toggle). Ask for reusable widgets: quizzes, simulators, diagrams.
NOTES.mdYour preferences (like "teach the name origins"). State a preference and it's recorded and honored.

The invisible engine: fighting forgetting

The skill explicitly distinguishes fluency (feels good now, fades) from storage strength (real retention), and chases the second through three techniques:

  • Retrieval practice — the recall quizzes. Answer before revealing; that effort is the point.
  • Spacing — reviewing after a gap, not just moving forward.
  • Interleaving — mixing topics in one session, like the interleaved review.

What's easy to leave unused

  • Learning records — the feature that makes future sessions calibrate to you instead of guessing.
  • Spacing & interleaving — going only forward, lesson to lesson, skips where retention is actually built.
  • Wisdom / communities — RESOURCES.md lists them; the whole "Wisdom" pillar is about testing skills with real people, not just the agent.
  • The agent as a live tutor between lessons — paste a confusing man page, an error, or a command you didn't recognise. That tight feedback loop is a core feature.

Phrases that drive it

  • "I already know X" → logs a record, skips it
  • "That was too easy / too hard" → recalibrates difficulty
  • "Quiz me on the last 3 lessons" → interleaved retrieval
  • "Make me a glossary / cheat sheet for X"
  • "Find me a good community for X"
  • "Change the mission to…"
  • "Review what I've learned so far"
