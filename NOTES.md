# Notes

- Beginner to the command line. Primary goal is general confidence, not just narrow task completion — explain *why*, not just *what to type*.
- Has working SSH access to a Synology NAS already, but is deliberately cautious about it. Don't have them run anything destructive or unfamiliar against the NAS. Flag risk level explicitly on any command that touches it.
- GitHub, Linux file system, and Synology SSH are the three contexts motivating this, but the mission is the shared skill underneath, not three separate tracks.
- **Teach the name origins.** For each command, tell them what it's short for (e.g. `cat` = concatenate) or the idea/story behind the name. They remember commands far better when the name means something. Weave it into lessons inline, and keep the consolidated list in `reference/command-origins.html`.
