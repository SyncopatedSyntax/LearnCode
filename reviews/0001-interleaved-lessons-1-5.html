Linux Command Line Confidence · Review 01

Interleaved Review — Lessons 1–5

Everything so far, deliberately shuffled. Harder than a per-lesson quiz — and that difficulty is the point.

How to use this

These questions jump between lessons on purpose. Mixing topics — interleaving — forces your brain to first work out which idea applies before recalling it, which is exactly the effort that builds long-term memory. It'll feel less smooth than reviewing one lesson at a time. That friction is the review working.

Rules: answer out loud (or in your head) before tapping to reveal. Tally what you get. There's no penalty for a miss — a miss just tells us exactly what to re-drill.

The questions

1. You've lost a file but remember its name. You know a phrase inside another file but not which one. Which command for each?

find searches by file name; grep searches for text inside files. (Lesson 0004)

2. You're inside a man page and your prompt has vanished. How do you get out?

Press q — man pages open in less, so the same quit key works. (Lessons 0005 + 0003)

3. What is cat short for, and what's its real job?

Concatenate — joining files end-to-end. Printing a single file is just the simplest case. (Lesson 0003)

4. Just by looking, how do you tell an absolute path from a relative one?

An absolute path starts with a leading slash /; a relative one doesn't. (Lesson 0001)

5. You SSH in, start typing your password, and nothing appears on screen. What do you do?

Keep typing and press Enter — hidden password input is normal and intentional. (Lesson 0002)

6. In a man page's SYNOPSIS, what do [ ] and ... mean?

Square brackets = optional; three dots = the item can be repeated. (Lesson 0005)

7. In grep -rin "synology" ., what do the three flags do?

recursive (search subfolders), ignore case, line numbers. (Lesson 0004)

8. What does cd - (dash) do?

Jumps back to the previous directory you were in — it toggles between the last two. (Lesson 0001)

9. Which single command confirms you're on the NAS and not your own laptop?

hostname — it prints the name of the machine you're currently on. (Lesson 0002)

10. What does the name grep actually stand for?

Global / regular expression / print — from the g/re/p command in the old ed editor. (Lesson 0004)

11. man isn't installed on your NAS. What's the reliable fallback for help?

Add --help to the command — it's built in and works almost everywhere. (Lesson 0005)

12. What's the difference between ls -a and ls -l?

-a = all (show hidden dotfiles); -l = long format (permissions, owner, size, date). (Lesson 0001)

13. Your terminal fills with garbage after you view the wrong file. What happened, and what fixes it?

You cat'd a non-text (binary) file; type reset and press Enter to restore the terminal. (Lesson 0003)

14. You want a command but only know what it should do. What do you run?

man -k keyword (or apropos keyword) to search the manuals by description. (Lesson 0005)

15. In find . -name "*.log", what does the . mean — and why the quotes?

. = start searching here (and all subfolders). Quotes hand the * pattern to find instead of letting the shell expand it first. (Lessons 0004 + 0001)
