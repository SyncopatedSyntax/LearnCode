Linux Navigation Cheat Sheet

Companion to Lesson 0001: Finding Your Way Around

CommandDoes
pwdPrint full path of current directory
lsList contents of current directory
ls -aInclude hidden files (dotfiles)
ls -lLong format: permissions, owner, size, date
ls -laBoth of the above together
cd <dir>Move into <dir> (relative or absolute path)
cd ..Move up one level, to the parent directory
cd ~ / cdJump to home directory
cd -Jump to the previous directory

Paths

  • Absolute: starts with / — works from anywhere, e.g. /home/you/Documents
  • Relative: no leading / — interpreted from current directory, e.g. ../Downloads
  • . = current directory, .. = parent directory, ~ = home directory

ls -l permission bits

-rw-r--r--  1 you  staff  220 Jun 10 18:02 .bashrc

Reading the first 10 characters of that line, left to right:

PositionCharsMeans
1-Type: - regular file, d directory, l symlink
2–4rw-Owner's permissions (read, write, execute)
5–7r--Group's permissions
8–10r--Everyone else's permissions
