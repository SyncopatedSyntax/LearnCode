SSH Cheat Sheet

Companion to Lesson 0002: SSH Into Your NAS

Connecting

CommandShort forDoes
ssh user@hostSecure ShellConnect to host as user
ssh -p 2222 user@hostSecure Shell · -p = portConnect on a non-default port (here, 2222)

The connect string, decoded

  • user — account name (on a Synology, must be in the administrators group)
  • @ — separator, "user at host"
  • host — the machine's IP (e.g. 192.168.1.50) or network name
