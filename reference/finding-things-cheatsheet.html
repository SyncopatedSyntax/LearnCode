Finding Things Cheat Sheet

Companion to Lesson 0004: Finding Things

The distinction: find = search by file name. grep = search for text inside files.

find — locate files by name

CommandDoes
find . -name "notes.txt"Find that file, from here down through subfolders
find . -name "*.log"Every .log file below here (quote patterns with *)
find ~ -name "budget*"Files starting with "budget", under your home dir
find . -type dOnly directories (-type f = only files)

find searches subfolders automatically. Its first argument is where to start.

grep — search inside files

CommandDoes
grep "error" file.logPrint lines in the file containing "error"
grep -i "error" file.logignore case (Error, ERROR, error)
grep -n "error" file.logShow the line number of each match
grep -r "error" .recursive: every file below here
grep -rin "error" .All three at once

Name origins

CommandShort for
findplain English — it finds things
grepglobal / regular expression / print (from g/re/p in the ed editor)
Two cautions: start searches from . or ~, not / (crawling the whole system is slow and noisy). And we're only locating here — find's -delete and -exec can change or remove files; save those for later, deliberately.

Source: The Linux Command Line — William Shotts.
