Permissions Cheat Sheet

Companion to Lesson 0008: Understanding Permissions

Reading the string

-  rw-  r--  r--
│   │    │    └─ others
│   │    └─ group
│   └─ owner (user)
└─ type: - file · d directory · l symlink
LetterOn a fileOn a directory
r readView itList contents (ls)
w writeChange itCreate/delete files inside
x executeRun itEnter it (cd)

chmod symbolic form

PieceOptions
Whou user/owner · g group · o others · a all
Direction+ add · - remove
Whatr · w · x

Examples: chmod u+x script.sh · chmod go-w notes.txt

Numeric form (decoding tutorials)

r=4 · w=2 · x=1, summed per group:

NumberMeans
7 = 4+2+1rwx
6 = 4+2rw-
5 = 4+1r-x
4r--
755rwxr-xr-x (owner all; others read+enter)
644rw-r--r-- (owner edits; others read)

"Permission denied" = your account lacks r, w, or x on the target. Diagnose with ls -l, don't guess. On the NAS: reading permissions is safe; changing them (or reaching for sudo) can break DSM services — not until it's deliberate.
