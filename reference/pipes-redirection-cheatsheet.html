Pipes & Redirection Cheat Sheet

Companion to Lesson 0007: Pipes & Redirection

The operators

SymbolMnemonicDoes
>arrow into a fileSend output to a file — overwrites it
>>double arrow = add onAppend output to the end of a file (safe)
|a pipe (plumbing)Feed the left command's output into the right command

Helper commands

CommandShort forDoes
echo "text""echo" (echoes back)Print text — often paired with >>
wc -lword count · -l = linesCount lines (also -w words, -c characters)
sortsortOrder lines (-n numeric, -r reverse)
historyhistoryList the commands you've run

Pipelines to steal

PipelineAnswers
ls | wc -lHow many items in this folder?
grep "error" log | wc -lHow many matching lines?
grep "error" log | lessPage through the matches
ls | sortFolder listing, sorted
history | grep sshPast commands mentioning ssh
> overwrites silently — same clobber risk as cp/mv. Use >> when you mean to add, not replace.
