YAML & Compose Cheat Sheet

Companion to Lesson 0009: Reading a Docker Compose File

The direction rule: in both ports and volumes, it's always HOST:CONTAINER — your NAS on the left, inside the container on the right. Change the left, leave the right.

YAML rules that actually bite

RuleDetail
Indentation = nestingHow far it's indented is what it belongs to. Structure, not decoration.
Spaces, never tabsTab characters are invalid for indentation — an invisible error.
Space after the colonkey: value ✓   key:value ✗
- makes a listA stack of dashes at the same indent is a list.
# is a commentEverything after it on the line is ignored.

The skeleton

services:
  my-app:              # a name you choose
    image: ...
    ports: ...
  another-app:         # second container
    image: ...

The keys you'll meet

KeyDoes
imageWhich prebuilt container to run. After the colon is the tag (version), e.g. :latest
ports"NAS:CONTAINER" — which door on your NAS opens into the app
volumes/nas/path:/container/path — real storage for the app. Add :ro for read-only
environmentSettings for the app: TZ, PUID/PGID, passwords
restartWhat happens after a crash or reboot (see below)
container_nameA fixed friendly name instead of an auto-generated one
depends_onStart this one after another named service

restart values

ValueBehaviour
noNever auto-restart (default)
on-failureOnly after an error exit
alwaysAlways, even after you stopped it
unless-stoppedAlways, unless you stopped it deliberately — usual pick for a NAS

Synology notes

  • DSM 7.2+: the Docker package is Container Manager; compose files go in a Project.
  • Host paths need the volume number: /volume1/docker/<appname>/config.
  • DSM itself uses some ports (5000/5001 among them) — don't claim those on the left.
  • PUID/PGID set which user/group the app acts as, so created files have workable permissions.
  • Deploy as a new Project rather than editing a working one.
Delete version:. The top-level version key is obsolete — ignored by modern Compose and warned about. If a tutorial still has it, the tutorial is old.
