Linux Command Line Confidence · Reference

Reading Files Cheat Sheet

Companion to Lesson 0003: Reading Files Without Changing Them

Commands

CommandShort forDoes
cat fileconcatenatePrint the whole file at once (best for short files)
cat a bconcatenatePrint files a then b joined together
less filepun on moreScrollable view for long files; q to quit
head filehead = topFirst 10 lines
head -n 5 filehead = topFirst 5 lines
tail filetail = endLast 10 lines
tail -f filef = followWatch a file live as new lines are added (Ctrl+C to stop)

Inside less

KeyDoes
SpaceDown one screen
↑ / ↓Up / down one line
/word + EnterSearch for "word"
qQuit back to the prompt
Garbled terminal? You probably cat'd a non-text file. Type reset and press Enter to restore it. When unsure if a file is text, use less instead of cat.
All read-only. Nothing here changes a file — safe to run anywhere, including the NAS.

Source: The Linux Command Line — William Shotts.
