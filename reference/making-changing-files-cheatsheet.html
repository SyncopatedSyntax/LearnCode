Making & Changing Files Cheat Sheet

Companion to Lesson 0006: Making & Changing Files

These change things — no undo, no trash. Practice on your own machine in a throwaway folder. Not on the NAS or system folders while learning.

Create

CommandShort forDoes
mkdir dirmake directoryMake a new folder
mkdir -p a/b/cmake dir · -p = parentsMake a nested path in one go
touch file"touch" (timestamp)Create an empty file (if it doesn't exist)

Copy & rename

CommandShort forDoes
cp a bcopyCopy file a to b
cp -r dir1 dir2copy · -r = recursiveCopy a whole folder
mv a dir/moveMove a into a folder
mv old newmoveRename (move to a new name)
cp -i / mv -i· -i = interactiveAsk before overwriting

Delete

CommandShort forDoes
rm fileremoveDelete a file — permanently
rm -i fileremove · -i = interactiveAsk before each delete (safer)
rm -r dirremove · -r = recursiveDelete a folder and everything in it
rm -fremove · -f = forceNo prompts or warnings
rmdir dirremove directoryDelete a folder only if empty (a safety net)
rm -rf force-deletes an entire tree with no confirmation. Never point it at a path you haven't read twice, never at /, and never with an unchecked wildcard.

Safety habits

  1. Sandbox destructive commands in a throwaway folder on your own machine.
  2. Use -i on cp/mv/rm while learning.
  3. ls a wildcard before you rm it: ls *.tmp then rm *.tmp.
  4. Read the path twice before any rm -rf. Not on the NAS or system folders.

Source: The Linux Command Line — William Shotts.
