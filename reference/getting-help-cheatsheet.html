The three ways to ask

CommandDoes
cmd --helpQuick summary, printed in place. Works almost everywhere (NAS too)
man cmdFull manual page, opened in less

Man page skeleton

SectionWhat's there
NAMECommand + one-line description
SYNOPSISHow to assemble the command
DESCRIPTIONFull detail and every option
EXAMPLESCopy-ready uses (jump here first)
SEE ALSORelated commands

Reading the SYNOPSIS notation

  • [ ] — optional
  • ... — can be repeated
  • plain words — type them as-is

Example: ls [OPTION]... [FILE]... = "ls, then any number of options, then any number of files, all optional."

The dash convention

  • -a — one dash, one letter: short form
  • --all — two dashes, a word: long form (often the same flag)
